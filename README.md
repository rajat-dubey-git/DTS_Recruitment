# DTS Recruitment & Staffing Platform — Phase 1

## Stack
React 18, Vite, TypeScript, React Router, Tailwind CSS, Axios, React Hook Form, Zod and Lucide icons.

## Run locally
1. Install Node.js 20+.
2. Extract this project.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Demo login

## Phase 1 scope
- Public landing page
- Validated login form
- Mock authentication context
- Protected application route
- Role-specific navigation shell
- Dashboard UI with illustrative sample data

## Important
This is a frontend-only Phase 1 prototype. Authentication is simulated in the browser and is NOT production security. Do not use real customer or candidate data. Replace the demo AuthContext with the Node.js API integration before deployment. Sidebar items are visual navigation placeholders until subsequent feature phases are implemented.
